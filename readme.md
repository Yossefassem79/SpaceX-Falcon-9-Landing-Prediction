# SpaceX Falcon 9 Landing Prediction

A Data Science and Machine Learning project focused on analyzing
SpaceX Falcon 9 launch data and predicting first-stage landing success.

## Project Overview

This project covers:

- Data Collection
- Exploratory Data Analysis (EDA)
- Data Visualization
- Interactive Dashboard
- Predictive Analysis
- Classification Models
- Model Evaluation
- Data-Driven Insights

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Plotly
- Folium
- Jupyter Notebook
